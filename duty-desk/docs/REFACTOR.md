## 阶段一：地基（先做）

### 1. 自动备份
- **做什么**：每次数据变更后（防抖 3 秒）或每天首次打开，导出 data/backup/YYYY-MM-DD.md
- **内容**：连续学习天数、本周签到 7 天、目标进度、今日三件完成度、近7天各科时长
- **验收**：backup 目录有按日期的 Markdown；用户复制整个目录即可在任意设备用文本软件读回自己的进度

### 2. 备考档案
- **做什么**：settings 存一份 profile（JSON）：阶段 / 目标院校专业 / 每天可学时长 / 各科当前进度 / 薄弱项 / 每周休息日
- **入口**：设置页「备考档案」表单（几行，不是长问卷）
- **验收**：能保存/编辑；调用 AI 时自动拼进 prompt

---

## 阶段二：主线（核心）

### 3. AI 生成计划
- **做什么**：新增「计划」入口，输入=备考档案（自动）+ 一句本周侧重（可选）；输出=月目标一句话 + 本周目标 + 未来 7 天每天三件
- **铁律**：① AI 是草稿，每个字可编辑 ② 固定每天 3 件 ③ 层级到月/周/日为止
- **确认后**：一键把 7 天三件写入 daily_cards
- **验收**：档案→AI→微调→确认→本周每日卡自动填充，全程一个页面完成

### 4. 月/周/日层级视图 + 进度表
- **做什么**：新增 plans 表（period: month/week，period_start，content，status）；层级视图展示 月目标 → 本周目标 → 今天三件；进度表=本周「计划三件 vs 完成三件」完成率
- **验收**：看板/计划页能看到三层 + 本周完成率百分比

### 5. 合并冗余 + 串数据（灵魂步骤）
- **合并记录（三处 → 一处分工）**：
  - 学习签到（study_logs）= 「今天学了什么」**唯一入口**，加 subject 可选标签
  - 每日卡晚复盘 note = 只留「卡在哪 / 明天干啥」，**去掉「今天学了啥」**（避免和签到重复）
  - 紧急记录（notes quick）= 随手记，独立不动
- **串数据（四套 → 一条线）**：
  - plans（月/周目标）→ daily_cards（日三件）→ study_logs（签到，带 subject）→ pomodoros（时长，带 subject）
  - 周进度表 = 目标完成率 + 三件完成率 + 各科时长 + 签到天数，一张表看全
- **验收**：记「今天学了啥」只有一处；周进度表同时含计划/打卡/时长/签到四项

## 阶段三：体验（用起来再加）

### 6. 休息日标记
- 每周休息日（默认周日），连续天数计算跳过，当天显示「休息」不断链

### 7. 打卡日历热力图
- 统计页近 100 天日历，签到绿 / 未签灰 / 休息浅色

### 8. 周核对流程
- 周日统计页顶部三步引导：本周数据 → 达成/部分/落后三选一 → 提示「只调一个变量」+ 下周目标输入

### 9. 三个小补丁
- 看板统计卡「连续打卡」改「连续学习」（主指标）
- 快捷指令 /study?text=xxx 一句话签到
- 看板显示「今日分科投入」
