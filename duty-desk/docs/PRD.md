## 数据流（自动沉淀）

| 行为 | 沉淀 | 用途 |
|---|---|---|
| 完成番茄 | pomodoros 表（科目/时长/时间） | 周报时间分布 |
| 录入错题 | wrong_answers + AI错因（概念/计算/思路/粗心） | 错题趋势、Anki卡片 |
| AI对话 | chat_messages + 知识库片段引用 | 复习回顾、检索增强 |
| 生成文书 | work_logs（AI成文/模板兜底） | 工作档案、模板复用 |
| 健身打卡 | fitness_logs（按日期去重） | 月度可视化 |
| 紧急记录/FDE | notes（kind=quick/fde/weekly） | 想法收集、周报归档 |

## 验收通过的实测项（v0.2）

- 番茄钟：开始→打断（记录类型+思路）→恢复→完成，时间日志正确入账
- 知识库：粘贴/文本/PDF导入→中文全文检索→AI回答注入（kbUsed=true）
- 错题：录入→后台AI分析（v4-pro约70秒）→错因+建议+变式题
- 文书：一句话→AI标准交接记录（aiUsed=true）；无Key时模板兜底
- Anki：按科目导出TSV（front/back/tags），Anki可直接导入
- 快捷指令：?auto=1自动开始番茄；?text=自动记录；iOS快捷指令可调用
- 周报：跨周检测提示→AI生成→自动归档可回看

## 已知限制

- PDF仅支持文字版；扫描件/图片版需OCR（后续可选接入）
- 数据存本地SQLite，云同步未做（可迁移Supabase）
- AI错因分析依赖v4-pro，推理约1分钟，后台进行不阻塞录入
- PWA离线缓存（Service Worker）未启用，弱网需在线
