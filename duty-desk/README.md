# 考研工作台（Study Desk）

**全职考研 · 专注四科。** 纯计划 + 时间 + 打卡 + 复盘的个人工作台：StudyLogix 式极简深色 UI、移动端优先、每日卡连续天数、初试倒计时。

> 定位说明：**不录入学习资料**（教材/题目/知识点都留在纸面和视频里），工作台只做「计划、计时、打卡、复盘」——把每天该做什么、做了多久、有没有断链看清楚。

## 功能一览

| 模块 | 功能 |
|---|---|
| 看板 | 考研倒计时 · 月/周目标 · 每日卡（三件+晚复盘+连续天数）· 学习签到 · 统计卡 · 目标进度 · 今日任务 · 今日动态 · 紧急记录 |
| 计划 | AI 生成月/周/日计划（备考档案驱动，可微调，一键填每日卡）· 层级视图 |
| 番茄钟 | 25/50 分钟 · 打断恢复（类型+思路）· 时间日志自动统计 |
| 记录 | 紧急记录（想法/待办）· FDE 边角时间收集 |
| 健身 | 固定计划打卡 · 连续打卡天数 |
| 统计 | 本周进度（三件完成率+签到）· 时间投入环形图 · 连续学习/打卡 · 最近番茄 |
| AI 助手 | 通用对话（deepseek-v4-flash）· AI 生成计划（deepseek-v4-pro） |
| 系统 | 备考档案 · 自动备份 · API Key · 初试日期 · 数据导出 · PWA · 快捷指令 |

## 快速开始

要求：**Node.js >= 22.5**（推荐 26，用 Node 内置 SQLite，零原生编译依赖）

    cd duty-desk
    npm install

    # 配置 DeepSeek API Key（可选，仅 AI 助手用；也可在设置页填）
    cp .env.local.example .env.local

    npm run dev          # 开发模式
    # 或
    npm run build && npm start   # 生产模式（推荐）

打开 http://localhost:3000

## 手机/平板访问

npm start 已绑定 0.0.0.0，同一 WiFi：macOS → 系统设置 → Wi-Fi → 已连接网络 → 详细信息 → IP 地址，手机浏览器打开 http://192.168.x.x:3000。
打不开时：系统设置 → 网络 → 防火墙 → 允许 Node 接受传入连接。

远程访问：cpolar（https://www.cpolar.com）注册安装后 `cpolar http 3000`，手机随时可访问。

## 每日卡 + 连续天数（核心）

- **早锚定**：写三件小事（带时段）
- **中执行**：白天逐个勾掉
- **晚复盘**：3 分钟写今天学了啥 / 卡在哪 / 明天干啥（次日自动衔接）
- **连续天数**：三件全勾 = 今天没断，断一天重计
- 周日自动提示「周核对」→ 统计页看本周数字汇总

## AI 生成计划（核心流程）

设置页先填「备考档案」（院校/阶段/时长/进度/薄弱项）→ 计划页点「AI 生成」→ AI 出月目标+周目标+未来7天每天三件 → 逐个微调 → 一键填入本周每日卡。
AI 生成用 deepseek-v4-pro（约30-60秒，规划任务更稳），日常问答用 flash。

## 手机离线 + 同网络同步（方案A）

- **手机首次在线打开一次**工作台（缓存应用壳 + 数据快照到手机浏览器）
- 之后**电脑关机**：手机浏览器访问同一地址，应用从缓存加载，可继续记「今日三件勾选 / 学习签到 / 加任务 / 紧急记录」（存手机本地）
- **电脑开机 + 同一网络**：打开工作台，顶部自动出现「有 N 条离线记录待同步」，点「立即同步」合并进电脑（冲突按时间取新）
- 同步后两边就是同一份数据

## 云端同步（坚果云）

账号已内置，**数据变更后自动推送到坚果云**（无需手动操作）。设置页也可手动「立即推送」/「从云恢复」。
数据在云端，电脑坏了/换设备都能恢复。

## 自动备份

任何数据变更后自动导出 data/backup/YYYY-MM-DD.md（连续天数、本周签到、目标进度、近7天时长），整个 backup 目录同步到 iCloud/坚果云即可防丢。

## 快捷指令（URL 一键触发）

| 指令 | 效果 |
|---|---|
| /pomodoro?auto=1&len=25 | 打开即自动开始 25 分钟番茄 |
| /pomodoro?auto=1&len=50&task=任务名 | 自动开始指定任务 |
| /notes?text=内容 | 打开即自动记录一条 |

iOS「快捷指令」App → 添加「打开URL」操作 → 粘贴完整地址（设置页一键复制）。

## 数据

- 全部本地：duty-desk/data/desk.db（SQLite，WAL）
- 备份：复制该文件；设置页可导出 JSON
- 清空重来：停止服务后删除 data/ 目录重启

## PWA

手机浏览器 → 菜单 →「添加到主屏幕」，全屏 App 式体验。

## 技术栈

Next.js 16（App Router + Turbopack）· React 19 · Tailwind CSS 4 · Node 内置 SQLite。

    app/          页面 + /api 路由
    components/   交互组件（每日卡/番茄/目标/时间轴/统计）
    lib/          db.ts（SQLite）· daily.ts（连续天数）· deepseek.ts（API封装）
    data/         运行时生成：desk.db
    scripts/      cleanup.mjs（清空数据）
